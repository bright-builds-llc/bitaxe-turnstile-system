Operator policy

This Gate deployment is run by Bright Builds LLC. It lets you earn a Gate Pass for an action, such as creating an account, by lending your Bitaxe's hashing to a pool for a few minutes instead of solving a puzzle or giving an email address.

How the Gate is run

  • Account creation uses the Standard policy: about 244 hashes, roughly 44 seconds on a 400 GH/s Bitaxe, within a 15-minute challenge.
  • Each service is operated only from its own host and command line. There is no remote administration route.
  • Records are kept and reduced as the privacy page describes.
  • If something the Gate depends on fails, it refuses rather than issues a pass it can't stand behind.

The software

The Gate is the open-source Bitcoin Work Gate from Bright Builds, under the MIT licence. The consent screen names the pool and the adapter your miner connects through, with their versions and source.

Contact

To report a problem or ask a question, open an issue on the project's public tracker at github.com/bright-builds-llc/bitaxe-turnstile-system/issues. Issues are public, so leave out personal details, payout addresses and anything that identifies your device.
