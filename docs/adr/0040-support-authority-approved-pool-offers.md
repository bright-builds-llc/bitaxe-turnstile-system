# Support authority-approved Pool Offers

A Work Challenge may carry a signed set of Pool Offers disclosing pool and adapter identity, transport, endpoint, Reward Policy, payout requirements, source, license, and operator terms. The Claimant may select among approved offers, but every choice satisfies the same Work Requirement and arbitrary untrusted substitution is prohibited; the reference v1 deployment may publish a single default while retaining the interoperable schema.
