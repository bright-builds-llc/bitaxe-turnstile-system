# Use SolidJS and Capacitor for v1 mobile applications

The v1 iOS and Android management applications will share SolidJS domain and UI packages with the web application through a Capacitor shell. Passkeys, QR scanning, push notifications, deep links, secure storage, NIP-46 handoff, and proven background constraints may use narrowly scoped native bridges; Reference Firmware connects directly to the Device Relay, so the phone does not need a persistent device transport or separate Swift and Kotlin product implementations.
