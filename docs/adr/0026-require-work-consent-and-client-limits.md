# Require Work Consent and client-side limits

Conforming clients will never start work on page load or treat Gate Policy as permission to use a Worker. Before each Protected Action, they will disclose exact and equivalent work, duration and energy estimates when available, Reward Policy, participating Workers, and cancellation behavior; a user-initiated Work Consent must satisfy claimant-configured limits and a client safety ceiling, and Gate Pass issuance ends the Work Lease rather than enabling hidden continuation.
