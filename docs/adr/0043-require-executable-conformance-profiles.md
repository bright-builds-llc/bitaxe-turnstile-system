# Require executable conformance profiles

Compatibility claims will target versioned Client, Gate Authority, Pool Adapter, Relying Service, or Worker Controller Conformance Profiles backed by reproducible executable fixtures and negative tests. The suite will cover exact work arithmetic, lifecycles, signatures and DPoP, deduplication, expiry, leases, rewards, API and Protobuf contracts, regtest mining, accessibility, and privacy; implementations may self-certify initially by publishing CI-reproducible results.
