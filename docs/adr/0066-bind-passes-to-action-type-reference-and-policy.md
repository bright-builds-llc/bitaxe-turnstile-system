# Bind Gate Passes to action type, reference, and policy

Every Gate Pass will bind a stable Protected Action Type, the exact opaque Action Reference, and the immutable Action Policy revision in addition to issuer, audience, challenge, Claimant key, and time. Several Action Policy revisions may belong to one type: the type determines what operation may execute, the reference identifies the one action instance, and the policy preserves the exact work and consent semantics that priced it.
