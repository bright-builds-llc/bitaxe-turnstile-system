# Ship a SolidJS Web Component and headless SDK

The reference website integration will be a framework-agnostic custom element implemented with SolidJS and Shadow DOM, distributed as both a hosted module and self-hostable package, with inline, modal, and full-page modes. A headless SDK will expose the same typed lifecycle for custom interfaces; iframe isolation remains optional rather than primary because local USB permission, accessibility, sizing, and cross-origin coordination complicate first-use Bitaxe onboarding.
